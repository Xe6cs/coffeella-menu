# Coffeella Café — Menu

قائمة كوفيلا كافيه (بغداد – حي الجامعة): موقع ثابت بسيط يعمل على الجوال والحاسوب، مع بحث فوري في الأصناف.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` | هيكل الصفحة |
| `styles.css` | التصميم والألوان |
| `app.js` | عرض القائمة والبحث والتنقل بين الأقسام |
| `menu-data.js` | **الأصناف والأسعار** — عدّل هذا الملف لتغيير القائمة |
| `brand.png` | شعار كوفيلا |
| `assets/` | صور الأقسام والواجهة |

## تعديل الأسعار

افتح `menu-data.js` وغيّر قيمة `price` للصنف:

```js
{ ar: "لاتيه", en: "Latte", price: [4000, 5000] }  // مدى سعري
{ ar: "اسبريسو", en: "Espresso", price: 3000 }      // سعر واحد
```

## التشغيل

لا يحتاج الموقع أي أدوات بناء؛ افتح `index.html` في المتصفح أو انشر المجلد كما هو على أي استضافة ثابتة (مثل GitHub Pages).
